Single-cell foundation models

Benchmarking a single-cell foundation model

  • 2026.05 – 2026.08
  • Abudayyeh–Gootenberg Lab, Harvard Medical School

A new model is only as convincing as the comparison behind it.

At a glance

Problem

Models are scored on different splits, genes and metrics.

Idea

Rebuild one published setting and run every model through it.

Status

Unpublished lab work, so results are not shown.

How it works

  1. 1Recover checkpointsGet every model running from released weights.
  2. 2Align gene spacesSame genes, same order, for every model.
  3. 3Matched evaluationSame held-out cells and metrics for all.
  4. 4Mean → populationApply a baseline's fold changes to real control cells.

My role

Summer research intern. Built the benchmarking pipeline and the mean-to-population conversion.
