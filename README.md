# Jingrui-Wu.github.io

Personal academic website of Jingrui Wu (吴京瑞), served by GitHub Pages at https://jingrui-wu.github.io/.

- `index.html` — homepage (no build step)
- `research/` — individual research pages
- `assets/Jingrui_Wu_CV.pdf` — CV; replace this file to update it

## Website analytics

Google Analytics 4 is loaded by `assets/analytics.js` only after a visitor accepts
optional analytics. The measurement ID belongs to the site's Analytics property;
it is a public identifier, not an API secret. The web stream uses
`G-8D44YTGGTQ` for `https://jingrui-wu.github.io` (stream `16300414707`).
An empty or invalid ID leaves tracking disabled.

All content pages include the shared script and stylesheet. `privacy.html`
explains the data collected. Visitors can decline or change their choice from
the footer. Google signals and advertising personalization are disabled.

The preference and analytics cookies last at most 180 days. Query strings and
fragments are omitted from the page and referrer URLs supplied to Analytics.
Adding another content page requires the two analytics asset links and footer
controls used on the existing pages.

After publishing, check the Analytics Realtime report with an opted-in visit.
Normal reports can take time to populate; visits made before installation are
not recoverable. Visitors who decline or block Analytics are not counted.
